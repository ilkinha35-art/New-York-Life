🗽 Jogo Nova York 3D

Simulação de tráfego urbano com carros e ônibus

🚦 Sobre o Projeto

Este jogo simula o tráfego de Nova York em ambiente 3D, com carros e ônibus fluindo pelas ruas, semáforos dinâmicos e rotas de transporte público.

🎮 Como Jogar

- Clone o repositório no GitHub
- Abra no Unity 3D
- Execute a cena NYC_Traffic.unity
