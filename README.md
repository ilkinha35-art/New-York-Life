# Jogo Nova York 3D - Tráfego Urbano

Este projeto simula o tráfego de carros e ônibus em Nova York em ambiente 3D.

## 🚀 Tecnologias
- Unity 2022
- C#

## 🎮 Funcionalidades
- Carros e ônibus fluindo pelas ruas em 3D
- Semáforos controlando o tráfego
- Sistema de colisão básico
- Ônibus com rotas e paradas
- Visualização em terceira pessoa ou câmera aérea

## 🛠️ Como rodar
1. Clone este repositório
2. Abra no Unity
3. Execute a cena `NYC_Traffic.unity`
